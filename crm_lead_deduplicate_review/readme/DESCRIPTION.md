Duplicate leads and opportunities, reviewed and merged with the
*Deduplication Review* engine.

CRM's own merge always keeps the most advanced lead. Here the reviewer
chooses, and CRM's merge steps run on that lead: field values (including
other modules' additions, such as quotations and event registrations), the
merge summary, messages, attachments, activities and calendar events. The
engine then moves everything those steps leave behind. Notably, that includes
the followers CRM's merge keeps only if they posted in the last 30 days.

It adds a *Duplicates* menu under the CRM leads, a *Review as Duplicates*
action on lead lists, and an inactive rule for leads with the same e-mail.
